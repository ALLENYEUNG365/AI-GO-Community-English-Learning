# Security Policy

## Reporting a Vulnerability

Please do not disclose suspected security vulnerabilities in public issues, pull requests, discussions, or other public channels.

If you discover a security issue, report it privately through GitHub's security reporting features when available. Include enough information to reproduce the issue, the affected component or endpoint, and any relevant logs or screenshots that do not contain secrets or personal data.

## Scope

This policy covers the production application, its source code, authentication flows, API routes, file-upload functionality, and deployment configuration maintained in this repository.

## Response

Security reports will be reviewed and addressed according to severity and impact. Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

## Secrets

Never include passwords, API keys, OAuth client secrets, database credentials, session secrets, or other sensitive credentials in an issue or pull request. Use environment variables and the repository's secret-management mechanisms instead.
